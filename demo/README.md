# 在线 Demo(免安装免 Key 试用)

本目录是 **Code2Offer 真实生成**的面试材料报告(example-demo 仓库,0.9.x 管线,60 题深度模式,质量门禁 A+ 100),经 GitHub Pages 自动部署:

**👉 https://12334rrr.github.io/Code2Offer/**

- `index.html` — 单文件自包含报告:搜索/筛选/隐藏答案自测/掌握度统计;题目里的 `文件:行号` 可点击,右侧词典式展示源码摘录;顶部分层架构图节点可点击联动面试题
- `架构图.svg` / `架构图.drawio` — 分层架构图;`.drawio` 在 [diagrams.net](https://app.diagrams.net)(免费)可继续编辑

重新生成:`npm run build && node dist/cli/index.js generate ./example-demo --mode deep`,把最新 run 的产物覆盖到本目录提交即可(Deploy Demo 工作流会自动重新部署)。
