- 引入 LangGraph 生命周期断点与可选 Tavily 公开技术参考(严格与代码证据隔离)。

## 0.5.2(2026-09-16)

输出分离:前一次与后一次的日志、产物不再堆在一起。

- **每次生成自动开启一个新的输出通道**(「代码转面试 · 仓库名 · 启动时刻」)并自动弹出;主通道保留全部运行的完整历史;移除任务记录时连同其专属通道一起清掉。
- **每次生成默认落入独立产物目录** `interview-output/runs/run-0001`、`run-0002`…(生成前可选:自动独立目录 / 固定 interview-output / 自定义目录),前后两次互不覆盖。
- 独立目录模式下增量缓存与断点自动从上一次接续:仓库没变的部分直接命中缓存,重跑几乎零成本;最终产物不携带,每个 run 目录自成完整快照。
- 「打开报告 / 产物 / 质量报告」自动定位最近一次完成的 run;CLI 的 rehearse/evaluate/topup 指向具体 run 目录即可。
- 显式指定输出目录(`--out`)时沿用旧的固定目录语义。

## 0.5.1(2026-09-16)

稳定性与多语言补丁。

- 阶段 0 新增多语言识别与常见 Dart/Rust/PHP/Prisma/Gradle/.NET 等工程依赖线索。
- 网络失败显示脱敏端点和原因码，便于排查 DNS、端口、代理、超时与 TLS。
- 推理型模型的严格 JSON 任务自动使用 `deepseek-chat`，避免 `deepseek-flash` 等模型把输出预算耗尽；项目叙述仍使用用户选择的模型。

## 0.5.0(2026-09-16)

A+ 工程升级：确定性证据链、请求策略、成本控制与报告体验。

- 新增 economy/balanced/deep 三种模式；生成前展示题量与调用范围、最大精读文件数和输出目录。
- API 客户端改为请求级预算与硬上限；非空截断不入缓存，401/403/400/404 不重试，429/408/5xx 尊重 Retry-After，取消立即生效。
- 画像过滤浏览器 profile、构建/缓存产物；新增 100–300KB 分段密钥扫描、便宜仓库快照和跳过原因统计。
- 阶段 1 大模块拆局部证据卡；阶段 2 批量与有界并发；阶段 3 动态装箱、并发校验和指纹 checkpoint。
- 新增质量门禁、主张账本、证据图、依赖清单和可复现运行清单；HTML 支持主题、组合筛选、搜索高亮、弱项练习和学习进度导出。
- Webview 结构异常时只安全降级到系统浏览器，VS Code 侧栏提示取消、缓存续接和错误类别。

## 0.4.0(2026-09-15)

品牌定名 **Code2Offer**;进度 UI 全面重做。

### 进度时间轴面板(侧栏「代码转面试」)
- 每个生成任务展开为**阶段节点时间轴**:画像 → 精读 → 出题(含修复环)→ 对抗校验 → 标红题重写 → JD → 总装 → 完成,共 8 节点
- 节点显示状态与**逐段用时**:✓ 完成 · 💿 门控命中缓存复用 · ⟳ 进行中(实时秒表)· ⊘ 跳过 · ✗ 失败 · ■ 已取消 · ○ 等待中;悬停查看每节点备注(如「pass 84 · fix 9 · flag 4 · 未覆盖 3」)
- 任务条实时汇总:已用时长、当前阶段、完成节点数;完成/失败/取消后条目保留可回看,🗑 单独移除,或一键清空记录

### 误点多次与并发控制
- **同一仓库去重**:误点 N 次不会产生第二个任务——弹窗提供「查看进度」(聚焦面板)与「取消并重新开始」(自动接回原参数)
- **不同仓库真并行**:各任务独立通知条、独立 ✕ 取消(标题栏一键全部取消);取消秒级生效,已完成阶段缓存全保留
- 内联操作按钮:运行中任务悬停出现 ✕(取消),已结束任务出现 🗑(移除)

### 其他
- CLI 更名入口:全局命令 `code2offer`(根 package.json bin);`--version` → 0.4.0
- runner 新增 `onStage` 结构化阶段事件宿主 API(CLI 行为不变)

## 0.3.0(2026-09-15)

全面安全与正确性修复(基于完整审计报告),建议所有用户升级。

### 安全
- 敏感文件拒绝清单:`.env`/私钥/凭据类文件绝不进入模型输入(独立于 .gitignore 生效),内容级密钥特征扫描兜底
- 端点与凭据同源绑定:被分析仓库的 `.env` 不能再把请求重定向到其他域名(防密钥外发),BASE_URL 强制 HTTPS(localhost 除外)
- 配置一次一解析:扩展不再写全局环境变量,多仓库各自使用自己的密钥/模型,互不污染

### 可用性(解决"运行很久没有任何反馈")
- 生成过程可取消:通知栏取消按钮,当前请求完成后立即停止,已完成阶段保留缓存
- 全部阶段日志进入专属输出通道「代码转面试」:每阶段横幅、耗时、重试警告、token 成本一目了然
- 阶段 1 模块精读并发 3、阶段 5 四份文档并行生成:推理模型下总时长大幅缩短
- 树视图状态实时刷新;记住本次生成目标,「打开报告/产物文件夹」不再找错目录

### 正确性
- 阶段门控改为内容哈希:等长修改代码、重新出题、修改答案都会正确触发重算(旧版会整链命中旧缓存)
- 校验闭环:模型失败/漏答的题标记 `未覆盖` 而非"通过";校验断点按输入指纹复用,不再把旧裁决套到新题
- 100 题配额:补题按"类别×难度缺口"定向回补,类别漂移被强制纠正;`topup` 有上限保护
- JD 分析输出形状校验:坏形状不再写入缓存造成"重跑必崩"
- 标红题重写保留原始裁决记录,校验报告按最终题库重算

### 报告
- 交互改为事件委托(无内联脚本):Webview 内搜索/筛选/自测标记全部可用,浏览器与 VSCode 行为一致
- 掌握度进度按仓库隔离(localStorage 命名空间),不同项目互不串扰
- 搜索覆盖追问链/加分回答/易错回答/对比表,150ms 防抖
- Markdown 表格单元格清洗:`|` 与换行不再破坏表格结构

### CLI
- 参数解析重写:`--top20 <目录>` 等布尔旗标在前不再吞掉路径参数;`--force <仓库>` 不再静默失效;新增 `--version`/`--help`
- 排练逐题落盘:中途退出不丢已答成绩;评分钳制 0-10,非法评分不再记 0 分污染弱项统计
- 自评环评委结果缓存:同一份材料重跑 evaluate 分数可复现;评委失败按"未评估"归一化,不再双重惩罚
