# Code2Offer(代码转面试 · Code → Interview Prep)

对**当前打开的代码仓库**一键生成真实面试场景的全套材料,由 DeepSeek 驱动:

| 产物(写入 `<仓库>/interview-output/`) | 内容 |
|---|---|
| `01_项目讲解.md` | STAR 三版本(1/3/10 分钟)、架构走读、技术选型横向对比 |
| `02_百问百答.md` + `index.html` | **100 题**,每题带 `文件:行号` 代码依据、追问链、对比表;HTML 报告可搜索/隐藏答案自测/掌握度统计 |
| `03_亮点与防守.md` `04_缺点与改进.md` | 亮点→追问→第一人称防守脚本;有准备的缺点话术 |
| `05_设计决策与选型对比.md` `06_速记卡.md` | 候选方案×维度×客观优劣×适用边界;考前 30 分钟版 |
| `校验报告.md` | 对抗校验:每道题的答案要点对照**引用处代码原文**逐条证伪,标红无依据的主张 |

与"把仓库丢给大模型问一句"的核心差别:先脚本画像(零幻觉事实层)→ 覆盖矩阵强制出题 → 对抗校验环 → 内容缓存 + 阶段门控(重跑只算变化的部分)。

## 上手(三步)

### 1. 配置密钥(任选其一)

- **推荐**:在**当前工作区根目录**建 `.env`:

  ```
  DEEPSEEK_API_KEY=***
  ```

- 系统环境变量:`setx DEEPSEEK_API_KEY sk-xxx`(Windows)/ 写入 `~/.zshrc`(macOS/Linux),设完重启 VSCode。
- 可选:`DEEPSEEK_MODEL`(默认 deepseek-chat)、`DEEPSEEK_BASE_URL`(自建网关)、`DEEPSEEK_TIMEOUT_MS`(超时,默认 300000)。

> 多根工作区/不想混在项目里:把 `.env` 放进扩展的全局存储目录也可被读到。
> 被分析仓库自己根目录的 `.env` 也会被读取,但**优先级最低**,且它的 `DEEPSEEK_BASE_URL` 只有在它自己也提供密钥时才生效(见「安全」)。

### 2. 生成

- 资源管理器**右键任意文件夹** → 「代码转面试:生成面试材料」;或 `Ctrl+Shift+P` → 同名命令。
- 会问你是否选择 **JD(岗位描述)文本文件**——选了就做岗位加权(必考 Top20 + STAR 定制);按 Esc 取消整个生成。
- 进度:右下角通知条 + **输出面板「代码转面试」通道**(`Ctrl+Shift+U` 选通道)逐阶段实时日志。
- **随时可点通知条上的「取消」**——已完成阶段自动缓存,下次从断点继续,不再烧钱。
- 全量生成通常 10–40 分钟(推理模型逐模块精读+百题校验,这是正常节奏;仓库越大越久)。

### 3. 看报告

- 完成弹窗直接点「打开报告」;之后可随时 `Ctrl+Shift+P` → 「代码转面试:打开面试报告」——`index.html` 在编辑器内打开,搜索/筛选/自测/掌握标记全部可用。
- 「打开产物文件夹」在系统文件管理器中定位 `interview-output/`。
- 标红的题(校验发现代码无法支撑的主张)会列在 `校验报告.md`,建议人工复核后再背诵——**这是特性,保证你面试说的每句话能在自己代码里指出来**。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示未找到 DEEPSEEK_API_KEY | 按上面第 1 步配置;错误消息里会列出全部可选位置 |
| HTTP 401 | 密钥无效(401/403/400 立即失败,不会空转重试) |
| 跑很久没反应 | 看输出面板通道,推理模型单次请求 2–6 分钟属正常;可随时取消(已花费进度保留);超大仓库建议改用 CLI 的 `--max-files` 控制精读范围 |
| 「该目录已有生成任务在运行」 | 同一输出目录有运行锁防互相覆盖;确认没有任务后删除 `interview-output/.run-lock` 即可 |
| 题目显示「? 未覆盖」 | 校验时模型漏答;重跑「生成面试材料」会自动只补验这些题 |
| 想换模型 | 「配置模型」命令,或在设置里填 `codeInterviewPrep.model`(优先级最高) |
| Windows 终端中文乱码(CLI) | `chcp 65001` |

## 安全与隐私

- **只有你的 DeepSeek(或自建网关)端点会收到请求**;无遥测、无任何第三方上报。
- `.env`、私钥、凭据类文件有独立拒绝清单 + 内容级密钥扫描,**绝不进入模型输入**(与仓库 .gitignore 无关)。
- **端点与凭据同源绑定**:克隆的恶意仓库不能靠它自己的 `.env` 把你的密钥引到攻击者地址;`DEEPSEEK_BASE_URL` 强制 HTTPS(`http://localhost` 调试网关例外)。
- 错误与日志中密钥一律打码;扩展**不写系统环境变量**,不跨仓库串用凭据。

## CLI(可选,同一核心库)

扩展只是薄壳;完整的命令行版(含 `evaluate` 自评、`rehearse` 交互排练)在同源码仓库:
`npm install && npm run build && node dist/cli/index.js generate <仓库> --jd jd.txt`
