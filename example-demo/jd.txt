岗位:Node.js 后端开发工程师(P3-P4)

职责:
1. 负责公司核心业务服务端 API 的设计与开发(Node.js/TypeScript);
2. 参与高并发场景下的性能优化,包括缓存策略、限流熔断、数据库索引优化;
3. 负责服务稳定性建设:监控告警、错误处理规范、灰度发布;
4. 参与技术方案评审,进行技术选型对比并输出决策文档。

任职要求:
1. 3 年以上后端开发经验,精通 Node.js 或其他服务端语言;
2. 熟悉常见数据结构与算法,理解 LRU、令牌桶等经典结构的工程应用;
3. 熟悉 HTTP 协议、RESTful API 设计,有输入校验与安全意识;
4. 有缓存(Redis/本地缓存)、限流、索引优化的实战经验;
5. 重视测试与工程化,有单元测试习惯;
6. 加分:有从 0 到 1 搭建服务的经验,能讲清技术选型的权衡与代价。
