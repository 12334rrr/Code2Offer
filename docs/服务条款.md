# Code2Offer(代码转面试)服务条款与费用说明

**最后更新:2026-09-17 | 适用于版本 0.9.0 及以上**

## 费用说明(重要,请先读)

- **本插件本身免费开源(MIT)**,不收取任何插件使用费;
- 插件调用的大模型 API **由你自行注册、自行付费**:默认使用 DeepSeek 官方 API,费用按 DeepSeek 官方计费规则直接结算给你与 DeepSeek 之间,开发者不经手、不分账;
- 生成一次完整材料的成本取决于模型定价与仓库规模(可用 `--max-files`/题量模式控制),请先用经济模式试跑;
- 你也可以配置任何 **OpenAI 兼容的自建网关**(`DEEPSEEK_BASE_URL`)。

> ⚠️ 诚实声明:提示词与请求路由针对 **DeepSeek 家族模型**深度调优(结构化任务自动路由到稳定模型)。其他 OpenAI 兼容端点在协议层可用,但输出质量未经过校准验证。

## 服务条款

1. **许可**:本软件按 MIT 协议开源,你可以自由使用、修改、分发(见 LICENSE);
2. **产出物用途**:生成的面试材料供你个人求职准备使用;题目的代码依据指向你自己的仓库,请确保你对被分析的仓库有合法使用权;
3. **免责**:
   - 生成内容由 AI 辅助产出,已通过「对抗校验 + 确定性质量门禁」控制准确性,**但不保证 100% 无误**;标红(⚠️)题目表示校验发现无法被代码支撑的主张,必须人工复核后再使用;
   - 对因使用本工具造成的任何直接或间接损失(包括但不限于面试结果、泄露你无权发送的代码),开发者不承担责任;
   - 模型服务(DeepSeek 等)的可用性、价格、条款由对应服务商决定。
4. **可接受使用**:不得将本工具用于生成与代码仓库无关的虚假经历材料,或任何违反目标公司招聘诚信政策的用途;
5. **条款变更**:重大变更将通过版本发布说明(CHANGELOG)公告。
