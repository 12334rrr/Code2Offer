# S 级人工验收清单(独立验收,agent 不得自评)

> 背景:0.8.0 已把"题题可背"做成结构与提示词双重强制,自动化验证(单测/冒烟/评委)全部通过。
> 但评委也是模型——以下两项**必须由人执行**,通过后才算 S 级正式版;此前版本历史里"真实 Extension Host 通过 ≠ 产品体验验收"指的就是这两项。
>
> 用法:对着最近一次**深度模式**生成的 run 目录逐项勾选;任何一项不过 → 记录题号/位置 → 修复后重跑,不得带病发布。

## A. 人工题库抽查(≥20 题,覆盖全部 11 类别)

从 `02_百问百答.md`(或 HTML 报告)按类别分层抽 20 题,逐题核对:

| # | 检查项 | 通过标准 |
|---|---|---|
| A1 | 代码依据可当场翻到 | 打开 `文件:行号`,所述实现就在该区间内;区间不超一屏 |
| A2 | 答案要点可直接背诵 | 每条 ≤70 字、一个记忆锚点;无"需确认/待补充"式占位 |
| A3 | 风险必有改进 | 凡要点指出风险/缺点,同条或次条给了可执行改进方案 |
| A4 | 追问有参考要点 | 每条追问下有 ↳ 参考要点,且方向正确(拿参考要点回答追问成立) |
| A5 | 难度分可信 | 难度分与你的面试经验一致(±2 以内),无全员同分 |
| A6 | 对比块客观 | 所选方案缺点真实存在;适用边界成立(抽查全部带对比的题) |
| A7 | 标红题处理 | `校验报告.md` 里 flag 题已人工复核或在重写后可信 |

记录格式:`Q23:A2 不过,要点第 2 条说的函数不存在(实际在 143 行)→ 转 fix`。

## B. UI 人工目检(F5 或安装 vsix 后,含一次真实生成)

| # | 检查项 | 通过标准 |
|---|---|---|
| B1 | 生成中时间轴 | 8 节点逐个点亮;进行中节点有秒表;门控命中显示 💿 |
| B2 | 独立输出通道 | 每次生成自动弹出「代码转面试 · 仓库 · 时刻」新通道,日志只在本次通道;主通道有完整历史 |
| B3 | 独立产物目录 | 第二次生成落 `runs/run-0002`,第一次 `run-0001` 原样在 |
| B4 | 增量接续 | 第二次生成(仓库未改)时大量节点 💿 缓存复用,总耗时明显缩短 |
| B5 | 误点去重 | 同仓库再点一次弹「查看进度/取消并重新开始」,不产生第二任务 |
| B6 | 取消/移除 | ✕ 取消后 ■ 已取消、缓存保留;🗑 移除后其专属输出通道同时消失 |
| B7 | 报告交互 | HTML 报告搜索"参考要点"能命中追问;难度分 chip 显示;筛选/自测/主题切换正常 |
| B8 | 打开产物 | 「打开报告/产物文件夹」定位最近一次完成的 run |

## 通过标准

- A 项:20 题中 **A1-A4 零失败**(S 级对"可背诵性"零容忍);A5-A7 允许 ≤2 处偏差且逐条记录。
- B 项:8 项全过。
- 两项都过 → 在 `docs/版本历史.md` 对应版本"发布状态"写"人工验收通过(日期+抽查题号区间)",方可 `vsce publish`。
