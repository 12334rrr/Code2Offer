# Code2Offer(代码转面试)隐私政策

**最后更新:2026-09-17 | 适用于版本 0.9.0 及以上**

## 一句话版本

你的代码只发送给**你自己配置的模型端点**(默认 DeepSeek 官方 API);本插件无遥测、无任何第三方上报、不在云端存储任何数据。

## 数据流向(全部链路)

1. **本地分析**:仓库画像(文件树/路由/热点)完全在本机完成,该阶段不使用任何模型;
2. **模型调用**:阶段 1-5 会把「分块后的代码原文 + 提示词」发送到你配置的 `DEEPSEEK_BASE_URL`(默认 `https://api.deepseek.com`)。发送什么、发给谁,全部记录在产物目录的 `run-manifest.json` 中(不含密钥);
3. **本地存储**:所有产物(题目/报告/缓存)只写入你仓库的 `interview-output/` 目录;掌握度学习记录只存在浏览器 localStorage(按仓库隔离);
4. **不收集**:本插件不采集、不上传任何使用数据、账号信息或代码副本到开发者或第三方。

## 密钥安全

- API Key 只从 `.env`/环境变量/扩展设置读取,仅在调用你配置的端点时使用;
- `.env`、私钥、凭据类文件有独立拒绝清单 + 内容级扫描,**绝不进入模型输入**;
- 仓库自带的 `.env` 无法把你的密钥重定向到其他域名(端点与凭据同源绑定,BASE_URL 强制 HTTPS);
- 日志与错误消息中密钥一律打码(只留前 8 位)。

## 外部参考(可选功能)

若配置了 Tavily Key,「公开技术参考」功能会把**通用技术关键词**(非你的代码)发送给 Tavily 搜索 API,结果只作为参考清单,不进入代码事实与题目引用。不配置则该功能关闭。

## 数据删除

删除仓库下的 `interview-output/` 目录即删除全部生成数据;卸载插件不保留任何远端副本(因为根本没有远端)。
